# Student Management System CLI

A Python-based Command Line Application to manage student records.
Developed using Git branching workflow to demonstrate team collaboration.

## Features
- Add Student
- View Students
- Search Student
- Delete Student
- Export to CSV

## Tech Used
- Python 3
- Git & GitHub
- Command Line Interface

## How to Run

Clone the repository:
git clone <repo-url>

Navigate to project:
cd Student_Manager

Run the application:
python3 main.py

## Team Workflow
Each member worked on separate feature branches.
All features were merged into main after resolving conflicts.

## Learning Outcome
- Git branching & merging
- Conflict resolution
- Modular Python development
